Understand the other beamline controls 9 choices

The shared workflow does not imply identical calibration or metadata guarantees across beamlines.

NOMAD: source bank / focused histogram

Select one source histogram per watch; verify what that grouping represents.

How it works. A focused Bank 1 is not necessarily detector bank 1. Different exports and groupings stay separate.

NOMAD: profile and Bank label in profile

Upload or select a reviewed .instprm; enter its actual Bank: label.

How it works. The app requires the supplied profile/physical-bank mapping to be confirmed. A detector-calibration HDF5 file is not a GSAS-II peak-shape profile.

NOMAD: allow unconfirmed sample corrections

Enable only for an exploratory analysis whose reduction corrections remain unconfirmed.

How it works. The analysis retains the exploratory qualification. It does not establish quantitative fractions or absolute intensities.

HB-2A preview: reduced-product normalization

Choose collection-time normalized, monitor normalized, or a reviewed legacy export before refreshing labels.

How it works. Product families and summed scans are not combined. Sample labels are scoped to their SPICE experiment.

HB-2A preview: automatic / supplied profile

Automatic selection needs an exact published date, Ge reflection and collimation match. Otherwise supply a reviewed CW profile.

How it works. An efficiency vcorr file is not the instrument peak-shape profile. Confirm reduction/profile suitability for the sample environment.

HB-2A: collimation and stopped scans

Use a reviewed IN/OUT override only when measured collimator metadata is absent. Allow stopped scans only after checking angular coverage.

How it works. An override cannot replace contradictory measurements. A stopped scan can have incomplete coverage.

HB-2A: measured channels and units

Bind the specimen channel and confirm its units: temperature K/C, magnetic field T, pressure GPa/bar in this UI.

How it works. Inactive SPICE channels are not treated as specimen measurements. The explicit review is retained with the condition.

SNAP preview: grouping / export variant

Select the intended mask/tag/reduction family and provide its matching reviewed profile.

How it works. A newer filename is not silently substituted for a different export. Quantitative calibration still needs review.

SNAP: specimen sensor and acquisition coverage

Select and verify a specimen-connected temperature readback with K/C units; confirm a full-run export.

How it works. An absent unit can be supplied after review, but conflicting NeXus units cannot be overwritten. Time-sliced exports need interval-specific conditions.

HB-2A and SNAP are marked preview in NOVA 0.4.34; their UI explicitly states that end-to-end NDIP validation remains pending. This AGES run does not validate those beamlines.

How it works. Runs up to one discovery pass with a small candidate and cell-search budget.

How it works. Allows up to two discovery passes and can stop early when improvement is insufficient.

Choose the fit interval and background 9 choices

Set these in the measured pattern's native coordinate before judging the fit.

Fit start (pattern x-axis) / Fit end (pattern x-axis)

Enter both endpoints to restrict a reviewed interval; leave both blank for the available pattern range.

How it works. TOF data use microseconds; constant-wavelength data use 2-theta in degrees. These controls do not take Q or d just because a display plot does.

Ignored regions

List start,end pairs for known invalid regions or justified environmental features.

How it works. Excluded bins are omitted from fitting and retained in provenance. They are not evidence of a successful fit in the omitted region.

Background correction: Automatic fixed points

Use when an estimated baseline is appropriate and inspect its result.

How it works. The pipeline estimates background support points. This changes the scientific preprocessing, unlike a display-only background subtraction.

Background correction: Manual / pipeline default

Use a reviewed explicit background model and configuration.

How it works. The background follows the submitted pipeline settings; selecting it does not create a hand-drawn point editor.

Function: chebyschev-1

Use a reviewed Chebyshev-polynomial background, as in the example.

How it works. Evaluates Chebyshev polynomials on the scaled native pattern coordinate.

Function: chebyschev

Use when an existing validated protocol specifies this distinct polynomial basis.

How it works. Uses powers of the scaled native coordinate. Its coefficients are not interchangeable with chebyschev-1.

Function: cosine

Use a cosine-series background only when it describes the smooth background adequately.

How it works. Uses a cosine basis in the native coordinate.

Function: Q^2 power series

Use a reviewed Q-based empirical background rather than choosing it from the filename alone.

How it works. Uses powers of Q squared, so the instrument/wavelength conversion is part of the calculation.

Background Terms

Start with a model that captures the smooth background without following the Bragg structure; the UI permits 1-36 terms.

How it works. More terms add flexibility and parameter correlations. A high count is not universally better.

The later LLM recipe deliberately extends to 11301.9103-281733.7203 microseconds. Its large background and noisy tail make the fit-domain warning important.

Changing analysis settings affects new jobs. Changing a chart's zoom or intensity scale does not refit the data.

How it works. Changes the width of predicted reference-peak exclusions, not the instrument resolution.

How it works. Resolution-based FWHM scaling and a fractional-d allowance help encompass the expected reference peak.

How it works. Adds tolerance to the predicted reference windows; blank uses the instrument-aware default.

How it works. The minimum must not exceed the maximum. These bounds do not alter the fitted peak widths.

Mask Cu K-beta companions

How it works. Adds the relevant companion exclusion windows; it has no role in the neutron AGES example.

Excluded space groups

How it works. It releases instrument terms under that assumption. It is not the automatic neutron cycle-profile resolver.

Magnetic residual precheck; Q maximum; denominators

How it works. The specified Q cutoff and integer denominators limit a diagnostic search. It does not refine a magnetic structure, determine moments or cover arbitrary incommensurate order.

Choose useful additional result plots 8 choices

Choose Additional result plots during setup; change the View selector after processing to inspect or revise a saved view.

Phase evolution

Track the modeled crystalline phase fractions through a scan series.

How it works. Reads refined weight fractions; missing phase points remain missing rather than being forced to zero.

Thermal expansion / cell change

Compare a, b, c or volume, including relative expansion and selected cross-phase lattice ratios.

How it works. Uses the refined cell and its uncertainty; it does not infer an unknown thermal-expansion law from a chemical name.

Lattice shape / distortion

Inspect c/a, b/a or orthorhombicity when the cell model can express the distortion.

How it works. Orthorhombicity here is (a-b)/(a+b). A constrained cubic or hexagonal equality cannot reveal a lower-symmetry degree of freedom that was never refined.

Reference lattice strain

Compare a cell length, volume or chosen d_hkl with a reference scan.

How it works. The normalized change can be shown in microstrain. This is a lattice-shift measure, not peak-width-derived microstrain.

Hysteresis curves

Separate heating/cooling or other qualified branches and optionally locate a chosen curve crossing.

How it works. Uses branch-qualified observations and interpolation of a selected response. It does not prove a thermodynamic transition.

Normalized progress proxy

Track a chosen fraction or lattice response between explicit start and end values.

How it works. Computes (value-start)/(end-start). This is a chosen proxy, not automatic reaction stoichiometry or kinetic-model fitting.

Operando correlation

Plot a refined observable against a measured or reviewed field, pressure, voltage or capacity axis.

How it works. Requires qualified conditions for the acquisition; a requested setpoint is not automatically a specimen measurement.

Sample / composition / preparation

Compare specimens with reviewed nominal-composition or preparation metadata.

How it works. Requires an explicit sample-state mapping and preserves the distinction between nominal and measured properties.

Broadening-based size/strain and atomic-geometry/site-order recipes are not offered by this version's Additional result plots selector. Default GPX values are not measurements. Refined atomic parameters can be reviewed in the LLM Refinement tab.

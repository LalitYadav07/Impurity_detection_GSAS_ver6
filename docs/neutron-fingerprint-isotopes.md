# Isotope-aware neutron fingerprints

Neutron fingerprints use `NeutronFingerprintCalculator` in the catalog builder
and lattice-nudging stick calculator. Natural-element inputs delegate directly
to the installed pymatgen calculator, preserving their existing calculations.
D and T remain separate species, including when they share a site with H; their
coherent amplitudes are added with the original occupancy of each component.
The global pymatgen scattering table is never modified.

The D/T constants come from the frozen GSAS-II `GSASII/atmdata.py` `AtmBlens`
table with SHA256
`f34011ec9e9f47088b42b840626443e0e4d7ff757de92b303d2be4a0e9f8ce66`.
Its D/H-2 value is `0.6681` and T/H-3 value is `0.4792`, in units of
10⁻¹² cm. Multiplication by ten gives **6.681 fm** and **4.792 fm**.
The D entry cites Snow (2020), DOI `10.1103/PhysRevD.101.062004` in the frozen
source. These values deliberately differ from older tables quoting D=6.671 fm.
Natural-element coefficients remain from the installed pymatgen table, so its
H=-3.739 fm baseline is retained. Generator receipts record both data sources
and the pymatgen version; the tables are not described as a single uniform set.

Pymatgen can equate H and D compositions during symmetry analysis. For an
isotope-bearing structure, symmetry metadata therefore uses explicit
species-and-occupancy integer labels with spglib. The source structure is never
standardized or averaged by that helper. A nonzero calculator `symprec` is
rejected for isotope inputs. Structural duplicate matching is skipped for such
candidates until an isotope-preserving matcher exists; byte-identical uploads
are still deduplicated.

This change consumes the shared CIF loader's Structure. Mixed H/D CIF loading
requires the accompanying raw-value occupancy-loader implementation; this
module does not implement a second CIF parser. Supported named isotope species
are D and T. It does not claim support for arbitrary isotope strings such as
`11B` or `7Li`, nor for isotope selection stored only in unrelated metadata.
Unsupported species must fail before fingerprint generation.

Each generated phase NPZ records a source SHA256, generator/table/dependency
identity, wavelength, angular window and top-M cut. Resume requires the exact
request hash; legacy or mismatched phase caches are rebuilt. In-memory nudge
caches include isotope identity, exact structure values and generator identity.
Profile bundles list receipts only for newly generated phase IDs. Inherited
base vectors are never relabeled as regenerated by the new calculator.

Validation covers analytic structure factors, mixed H/D amplitudes, D/T
coefficients, unchanged natural-element arrays, isotope-ordered symmetry,
stale-cache rebuilding and combined shared-loader-to-builder execution on the
native and frozen Linux runtimes. This changes candidate fingerprint physics;
it does not change the native GSAS-II refinement protocol.
